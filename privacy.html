⚡ Serverless Web Application

[퐁크러쉬] 개인정보처리방침

'퐁크러쉬'는 이용자의 개인정보를 소중히 다루며 관련 법령을 준수합니다.

서버리스(Serverless) 무료 웹 애플리케이션
'퐁크러쉬'(이하 "서비스")는 별도의 백엔드 서버 없이 사용자의 브라우저 내에서만 동작하는 순수 클라이언트 기반 서비스입니다. 사용자의 개인 데이터는 개발자의 중앙 서버로 전송되거나 보관되지 않습니다.
🔒 중앙 서버 저장 ZERO
💻 기기 내 로컬 구동 (WebLLM/GPU)
🚫 제3자 제공 및 판매 금지
1

수집 및 처리하는 개인정보 항목

📚 학습 데이터 및 설정값 로컬 저장
단어 학습 기록, 취약 단어 목록, 체크 횟수, 음성/재생 설정, AI 파라미터 값
처리 방식: 사용자의 기기 브라우저 내부 저장소(LocalStorage, CacheStorage)에만 안전하게 저장됩니다.
🔑 구글 계정 인증 정보 선택 항목
Google OAuth 접근 토큰(Access Token)
처리 방식: 사용자가 '구글 드라이브 백업/복원' 기능을 직접 실행할 때만 연동되며, 발급된 접근 토큰은 브라우저 세션 메모리에서만 일시적으로 사용된 후 즉시 소멸합니다.
🎙️ 음성 데이터 선택 항목
마이크를 통한 스피킹 음성 데이터
처리 방식: 브라우저의 내장 Web Speech API 및 Web Audio API를 통해서만 실시간 분석되며, 외부 서버로 전송되거나 저장되지 않습니다.
2

개인정보의 처리 목적 및 보유 기간

  • 처리 목적: 브라우저 내 오프라인 단어 학습, 취약 단어 복습, 사용자 본인의 구글 드라이브 파일(pongcrush_sync_data.json) 백업 및 복원, 로컬 AI 첨삭 및 발음 분석을 위해서만 사용됩니다.
  • 보유 기간: 서비스 제공자의 중앙 서버에는 어떠한 데이터도 저장되지 않습니다. 사용자가 브라우저의 캐시/사이트 데이터를 삭제하거나 직접 연동을 해제하면 기기 내 데이터는 즉시 영구 삭제됩니다.
3

개인정보의 제3자 제공 및 위탁

  • 본 서비스는 이용자의 개인정보를 제3자에게 제공하거나 외부에 위탁하여 저장·처리하지 않습니다.
  • 로컬 AI 기술 (WebLLM): 로컬 AI 영작 첨삭 기능은 사용자의 기기 GPU(WebGPU)를 활용하여 브라우저 내에서 직접 구동되므로 입력 문장이 외부 AI 서버로 일절 전송되지 않습니다.
4

Google API 사용자 데이터 정책 준수 (Limited Use)

본 서비스는 사용자의 백업 파일 생성 및 관리를 위해 최소한의 구글 드라이브 접근 권한만을 요청합니다.

요청 권한 범위 (Scope):
https://www.googleapis.com/auth/drive.file
  • 서비스는 본 앱이 생성한 백업 파일(pongcrush_sync_data.json) 외에 사용자의 드라이브 내 다른 파일에 절대 접근하지 않습니다.
  • 구글 사용자 데이터를 본래의 백업/동기화 목적 외에 다른 용도로 수집, 전송, 마케팅에 활용하거나 판매하지 않습니다.
5

이용자의 권리 및 문의

  • 로컬 데이터 및 권한 관리: 이용자는 브라우저 설정을 통해 언제든지 저장된 로컬 데이터를 삭제하거나, 마이크 권한을 차단할 수 있습니다.
  • 구글 계정 연동 해제: Google 계정 보안 설정(보안 > 타사 앱 및 서비스) 페이지에서 연동 권한을 언제든지 철회할 수 있습니다.
